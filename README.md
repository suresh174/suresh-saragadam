# Suresh Saragadam — Portfolio

Personal site and AI Engineer resume for **Suresh Saragadam**.

- Target domain: [sureshsaragadam.vercel.app](https://sureshsaragadam.vercel.app)
- Stack: Next.js (App Router), TypeScript, Tailwind CSS
- Content: `src/data/profile.ts`
- ATS resume PDF: `public/Suresh-Saragadam-Resume.pdf`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Resume PDF

Regenerate the ATS resume:

```bash
npm run resume:pdf
```

Requires Google Chrome installed locally.

## Deploy

Connected to Vercel from this GitHub repository. Push to `main` to redeploy.
