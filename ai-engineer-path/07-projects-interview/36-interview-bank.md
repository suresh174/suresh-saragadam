# 36 — Interview question bank

## Small talk

Practice **out loud**. Silent nodding ≠ interview ready.

Tick when you can answer in ~2 minutes with an example.

---

## Foundations

- [ ] AI Engineer vs ML Engineer vs Data Scientist?
- [ ] Train / val / test — why three?
- [ ] What is data leakage? Example?
- [ ] Bias vs variance?
- [ ] Precision vs recall — when each matters?

---

## Classical ML

- [ ] Walk through a classification pipeline end-to-end
- [ ] Why pipelines in sklearn?
- [ ] How do you handle imbalanced classes?
- [ ] Regularization — what / why?
- [ ] Tree model vs linear model — when?

---

## Deep learning

- [ ] What does a linear layer do?
- [ ] Why activations?
- [ ] Explain backprop without equations panic
- [ ] Dropout / batchnorm — intuition?
- [ ] CNN vs MLP for images?
- [ ] Self-attention in plain words?
- [ ] Why transformers beat RNNs for many NLP tasks?

---

## LLMs / NLP

- [ ] What is a token?
- [ ] Embeddings — what problem do they solve?
- [ ] Prompt vs RAG vs fine-tune — decision tree?
- [ ] Draw RAG architecture
- [ ] How do you evaluate a RAG system?
- [ ] What is prompt injection?
- [ ] LoRA — why use it?
- [ ] Agent vs single LLM call?

---

## MLOps / production

- [ ] Notebook → API concerns?
- [ ] What do you log in an LLM service?
- [ ] How do you control LLM cost?
- [ ] Blue/green or feature flag for prompt change?
- [ ] Cold start / model loading strategy?

---

## Behavioral

- [ ] Tell me about a hard debugging story
- [ ] Disagreement with a teammate on model choice
- [ ] Time you shipped something imperfect on purpose (tradeoff)

---

## How to drill

1. Pick 5 unchecked  
2. Answer on a timer (2 min)  
3. Note gaps → revisit topic MD  
4. Repeat next day  

---

## Checkpoint

- [ ] 20+ boxes ticked with confident answers
- [ ] Capstone story rehearsed
